AGGREY MEMORIAL WEBSITE PACKAGE (GITHUB PAGES READY)

Included files at ZIP root:
- index.html: main website
- style.css: responsive design and layout
- script.js: mobile menu, photo lightbox, back-to-top and graceful image fallback
- manifest.json: installable web-app metadata
- service-worker.js: offline cache
- images/: 10 locally bundled photos used by the site

STUDENT PORTAL
The sample/demo student portal was completely removed. There are no fake student accounts, passwords, grades or demo results. A real student portal requires an authorized secure backend and database.


PUBLISH TO GITHUB PAGES
1. Extract this ZIP.
2. Upload the CONTENTS of this package directly to the repository root (index.html, style.css, script.js, manifest.json, service-worker.js, README.txt and the images folder). Do not upload an enclosing aggrey_complete_site folder.
3. In the repository, enable GitHub Pages for the main branch and root folder if not already enabled.
4. Wait for the publish workflow and open the Pages URL. After updating, if an old cached version appears, refresh or clear site data; the service-worker cache version was updated.


PHOTO FILES
The image references are relative to index.html and style.css and point to the included images/ folder. All referenced image files are included in this package.


IMPORTANT
This is an informational website project, not a verified official school publication. Verify school-specific facts, contact information, and permission to publish before launch.
